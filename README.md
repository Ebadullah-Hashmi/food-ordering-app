# Food Ordering App

A native Android application built with Java that provides a complete food ordering experience, featuring a smart chatbot assistant to help users find and order meals seamlessly.

## Core Features

* **User Authentication:** Secure Login and Signup using Firebase.
* **Smart Chatbot Assistant:** Built-in conversational AI to help users navigate the menu and place orders intuitively.
* **Cart Management:** Browse food items, adjust quantities, and manage the shopping cart in real-time.
* **Payment Integration:** Secure checkout process for finalizing food orders.
* **Cloud Backend:** Powered by Firebase for instant data syncing and user management.

## Tech Stack

* **Frontend:** Java (Android SDK)
* **Backend & Database:** Firebase (Authentication, Realtime Database / Firestore)
* **IDE:** Android Studio
